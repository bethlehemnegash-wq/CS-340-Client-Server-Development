# CS 340: Client/Server Development

## Module Eight Journal Reflection

### How do you write programs that are maintainable, readable, and adaptable?

I write programs that are maintainable and readable by keeping my code organized, using clear names, and separating different functions. In Project One, I created a CRUD Python module that handled the database operations for MongoDB. I was able to reuse that same module in Project Two when building my dashboard for Grazioso Salvare. This made the process easier because I didn't have to rewrite the database connection or CRUD operations. It also allowed me to focus more on the dashboard functionality. In the future, I could use this same approach when developing other applications that need to retrieve, update, or manage database records.

### How do you approach a problem as a computer scientist?

I approach problems by first understanding the requirements and then breaking them into smaller tasks. For the Grazioso Salvare project, I had to understand how the animal shelter data was organized before creating queries and connecting the database to the dashboard. I worked on the database connection, filtering, and dashboard components separately before bringing everything together. This project was different from previous assignments because I had to think about how the application would actually be used by a client instead of just making sure my code worked. In the future, I would continue testing each component individually and making sure the database structure supports the client's needs.

### What do computer scientists do, and why does it matter?

Computer scientists develop solutions that help organizations manage information, improve processes, and solve problems using technology. This project showed me how programming and databases can work together to make information easier to access and understand. For Grazioso Salvare, the dashboard helps organize animal shelter records and allows users to filter information to identify dogs that meet specific rescue training criteria. Instead of manually searching through records, users can access the information through an interactive dashboard. This can save time, reduce errors, and help the organization make better decisions. I can see myself applying these same skills in future projects involving database management, automation, and software development.
